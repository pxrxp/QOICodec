# Security Policy

Please do not report security problems in a public issue or pull request.

Use the **Report a vulnerability** option on the repository’s [Security tab](https://github.com/pxrxp/QOICodec/security) to send a private report, if it is available. If it is not available, contact the maintainer privately through [pxrxp’s GitHub profile](https://github.com/pxrxp).

Include the steps needed to reproduce the problem, its possible impact, and any relevant files or versions. Please give the maintainer a chance to investigate before sharing details publicly.

There is no separate supported-version list; security reports about the current code in the default branch are welcome.
