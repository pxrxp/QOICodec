# Code of Conduct

## Our standard

Be respectful and constructive. Critique code and ideas, not people. Keep discussions focused on the project, and be patient when someone is learning or asking a question.

Harassment, insults, discrimination, personal attacks, and deliberately disruptive behavior are not welcome in this project’s issues, pull requests, or other community spaces.

## If something happens

If you see behavior that does not meet this standard, contact the maintainer privately through [pxrxp’s GitHub profile](https://github.com/pxrxp). Please include a link or enough context to understand what happened. The maintainer will review the report and decide what action is appropriate.

This applies to everyone taking part in QOICodec community spaces.
